## Cambiar el idioma [#change-the-language]

<Steps>
<Step>
### Abre el menú de idioma [#open-the-language-menu]

Elige el botón de idioma en la barra superior.
</Step>
<Step>
### Elige un idioma [#pick-a-language]

La página se recarga en ese idioma, en la misma dirección con su código de idioma (`/es/formats`).
</Step>
<Step>
### Vuelve a leer los valores [#read-the-values-again]

Las fechas, los números y el dinero ahora siguen las reglas de ese idioma, tal como las define el
[Unicode CLDR](https://cldr.unicode.org/).
</Step>
</Steps>
