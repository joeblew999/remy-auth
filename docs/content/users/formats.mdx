The Formats page shows one set of values the way your language writes them: dates, times, numbers,
money and the direction of the text.

## Change the language

<Steps>
<Step>
### Open the language menu

Choose the language button in the top bar.
</Step>
<Step>
### Pick a language

The page reloads in that language, at the same address with its language code (`/es/formats`).
</Step>
<Step>
### Read the values again

Dates, numbers and money now follow that language's rules, as the
[Unicode CLDR](https://cldr.unicode.org/) defines them.
</Step>
</Steps>
