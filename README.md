# Remy Auth

Shared authentication for Remy apps, using **Better Auth on Cloudflare Workers**, and the shared UI
package `@joeblew999/remy-ui` its apps are built on.

The documentation is the docs site, https://remy-auth.gedw99.workers.dev/docs (the guide) and /dev (developer docs), built with Fumadocs
from [content/docs](content/docs/) (also as Markdown for tools: `/docs/llms.txt`, `/dev/llms.txt`). Agents start at
[AGENTS.md](AGENTS.md); open work is in [.plans/now.md](.plans/now.md); releases in
[CHANGELOG.md](CHANGELOG.md).
