# @joeblew999/remy-cli

The Remy platform's command line: `remy` and `remy-check`. It does the jobs Vite Plus has no tool for: GitHub and
landing, Cloudflare deploys, translations, the project's own checks and an installation's setup. Every Remy app
installs it beside `@joeblew999/remy-ui`; its scripts and Vite Plus tasks run it.

Every command: [COMMANDS.md](https://github.com/joeblew999/remy-auth/blob/main/COMMANDS.md).
