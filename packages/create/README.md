# @joeblew999/create

New Remy apps, as Vite Plus makes an organization's apps ([its guide](https://viteplus.dev/guide/create#organization-templates)):

```bash
vp create @joeblew999:app --directory my-app
```

`templates/app` is the blank app every Remy app starts from, copied as it is (`_gitignore` and `_npmrc` become their
dotfiles). How a new app goes from there: [Projects](https://remy-auth-docs.gedw99.workers.dev/dev/projects).
